# FinancialAppTS

**FinancialAppTS** — веб-приложение для учета личных финансов, созданное на Angular.

Проект позволяет отслеживать доходы и расходы, создавать собственные категории операций и анализировать финансовые данные с помощью дашборда.

---

## 📋 О проекте

Приложение предназначено для удобного ведения личного бюджета.

Пользователь может добавлять финансовые операции, распределять их по категориям и просматривать общую статистику по доходам и расходам.

Основная информация отображается на дашборде в наглядном виде, что помогает оценивать текущее финансовое состояние и структуру расходов.

---

## ✨ Возможности

- Добавление доходов и расходов
- Создание и управление категориями
- Просмотр списка финансовых операций
- Отображение общей суммы доходов
- Отображение общей суммы расходов
- Расчет текущего баланса
- Фильтрация операций
- Просмотр финансовой статистики на дашборде
- Визуализация данных с помощью диаграмм
